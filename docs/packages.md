# Packages

Internal workspace packages shared by the apps. All are built with `tsc` and
published as workspace-only packages (no npm publication — they resolve via
`pnpm-workspace.yaml`).

## `@filmsnaps/shared`

**Dir:** `packages/shared`

Shared logic consumed by every app. The postinstall hook at the repo root
builds it automatically (`pnpm --filter @filmsnaps/shared build`).

**Scripts:** `build` (`tsc && node scripts/fix-dist-imports.mjs`), `dev`,
`typecheck`, `test`.

**Exports:**

| Subpath      | Contents                                                |
| ------------ | ------------------------------------------------------- |
| `.`          | Barrel: guard script builder, providers, types, utils.  |
| `/security`  | `playerGuard.ts`, `scriptlets.ts`, `navigation-home.ts` |
| `/providers` | `registry.ts` (provider single source of truth)         |
| `/types`     | movie + provider types                                  |
| `/api`       | TMDB helpers                                            |
| `/state`     | `useWatchHistory` + storage layer                       |
| `/theme`     | design tokens                                           |
| `/utils`     | `cn`, image, video                                      |
| `/constants` | TMDB constants                                          |

The `fix-dist-imports.mjs` postbuild step normalizes ESM imports in the
compiled output so consumers (Next.js, React Native, Electron) can import it
cleanly.

## `@filmsnaps/adblock-config`

**Dir:** `packages/adblock-config`

Schema, types, and validation for `providers.json` + `filters.txt` (v5).

**Scripts:** `build`, `typecheck`, `validate` (`tsx src/validate-cli.ts`).

**Files:** `src/types.ts` (schema), `src/loader.ts` (load + parse),
`src/validator.ts` (schema validation), `src/validate-cli.ts` (CI entry point).

Desktop does **not** import this package at runtime — Electron main is CommonJS
and never imports `@filmsnaps/*`. Instead it has a CJS replica loader at
`apps/desktop/src/security/provider-config.ts` that must stay in sync with the
schema here.

## `@filmsnaps/filter-compiler`

**Dir:** `packages/filter-compiler`

Produces the deployable adblock artifacts from `filters.txt` + uBO/EasyList lists.

**Scripts:** `build` (`tsc`), `compile` (`node dist/compile.js`),
`compile:dev` (`tsx src/compile.ts`).

**Outputs:**

- `build/compiled-engine.bin` — serialized `@ghostery/adblocker` FiltersEngine
  (desktop R4; loaded by `apps/desktop/src/security/filter-engine.ts`).
- `android-adblock-patterns.json` — substring/domain patterns shipped inside the
  APK (mobile `AdblockEngine` + desktop R4b). Generated by `src/export-android.ts`.
- `minimal-guard` — a stripped-down guard variant (`src/minimal-guard.ts`).

**Flow:** run `pnpm build:filters` at the repo root to recompile all artifacts
after editing `providers.json` or `filters.txt`.

## Adding a new package

1. Create the dir under `packages/` (it's picked up by `pnpm-workspace.yaml`).
2. `package.json` with `"private": true`, a `@filmsnaps/<name>` name, and a
   `build` script (`tsc`).
3. Export a `dist` subpath via the `exports` map so apps can import it.
4. If apps should be able to `pnpm add @filmsnaps/<name>`, use `pnpm add` from
   the consuming app (workspace resolution).
